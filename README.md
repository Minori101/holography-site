# Голография — сайт-визитка

Одностраничный сайт по макету Figma «Сайт-визитка — Голография» (Desktop 1440), с адаптивом для планшетов и телефонов.

- Чистые HTML + CSS, без сборки: `index.html`, `assets/styles.css`
- Шрифты Unbounded и Manrope (SIL OFL) лежат локально в `assets/fonts`
- Фото экспортированы из макета в WebP: `assets/img`
- Хостинг: GitHub Pages из ветки `main`, корень репозитория

Локальный просмотр: `python3 -m http.server` в корне репозитория.
